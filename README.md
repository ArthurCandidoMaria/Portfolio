# Arthur Candido Maria - Industrial Portfolio

Professional React portfolio website with an industrial visual identity, built for AI, engineering, and industrial automation projects.

## Stack

- React (functional components)
- Vite
- Tailwind CSS
- Lucide React icons

## Run locally

1. Install Node.js LTS from https://nodejs.org/
2. Install dependencies:
   - `npm install`
3. Start development server:
   - `npm run dev`
4. Build for production:
   - `npm run build`

## Project structure

- `src/components` - Modular UI sections and reusable section title
- `src/data/portfolioData.js` - Portfolio content data
- `src/App.jsx` - Main page composition
- `src/index.css` - Global styles and industrial theme helpers

## Sections included

- Hero
- About Me
- Education
- Professional Experience
